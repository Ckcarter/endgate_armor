End Portal Armor - Forge 1.20.1 starter mod

What is included:
- Helmet, chestplate, leggings, boots
- Animated armor texture cycling using 8 frame textures
- Creative tab entry
- Placeholder item icons and placeholder portal-style armor textures

Important notes:
- This starter uses normal armor rendering with animated texture swapping.
- It looks portal-themed and animated, but it is not a full custom shader.
- I did not run a full Forge build in this environment, so you may need small mapping/import fixes depending on your setup.

How to use:
1. Open the folder as a Gradle project in IntelliJ.
2. Let Gradle import.
3. Generate run configs if needed.
4. Run the client.

How to improve it later:
- Add a custom armor model for an open-face helmet.
- Add an emissive overlay pass.
- Replace placeholder portal textures with your own art or a closer end-portal animation.
